# @lenticule-science/articulating-language-cone-service

This package projects the one `articulate-utterance` operation through canonical
RMN, signed A2A, ActivityPub, and MCP faces. All faces share the immutable apex
identity derived from the established SCIS v2 object-kind/value/witness-root law.

The public server accepts ActivityPub-carried A2A RMN messages. Runtime and
credential mechanics remain injected at the boundary; they are not part of the
operation identity.

The core operation and RMN/EVM projection do not depend on a federation server.
The ActivityPub CLI and async public entry retain their original wire protocol and
accept an explicitly installed compatible optional ActivityPub peer. Importing
the package or its RMN face loads no federation adapter or SQL implementation.

Canonical executable source is services/articulating-language-cone-service in
red-cup-engineering/articulating. The independently published 0.1.5 artifact
(sha512-4fEAInOcZGQtrdNkwNDdRhRpl1su1BsQZH+fiI2ezP4WlLAceZCYSNmBiVQuapv886bG1o8zy1mr4HYL6YXSrg==)
receives the preserved six source members; operation/apex/RMN/A2A/MCP and public
server bodies are unchanged. This source corrects dependency admission and the
eager public-entry import, preserving the optional async public-server API.
